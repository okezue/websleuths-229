    \heading{Training Recipes}

    Our primary recipe is \textbf{EATRD}: $\mathcal{L} = \mathcal{L}_{\mathrm{ep}} + \lambda\, \mathcal{L}_{\mathrm{dr}}$, combining authority-weighted CE with temperature-scaled KL against the frozen teacher, where a PI controller adapts $\lambda$. All models use qLoRA (rank 32, lr $3\!\times\!10^{-4}$, batch 2) on Qwen2.5-1.5B. We also tested:
    \begin{itemize}\setlength{\itemsep}{4pt}
        \item \textbf{DPMU}: gradient projection orthogonal to dream gradients. Matched accuracy but higher drift from stale caches.
        \item \textbf{EAB-SSC}: fixed dream weight + SVD adapter consolidation. Under-regularized early, over-regularized late.
    \end{itemize}

    \heading{Authority Rankers}

    Each document gets $w_i = \alpha \hat{r}_i + (1\!-\!\alpha) s_i$ blending search relevance with a method-specific score ($\alpha\!=\!0.5$). We tested four rankers:
    \begin{itemize}\setlength{\itemsep}{4pt}
        \item \textbf{Base}: unweighted PageRank over the link graph.
        \item \textbf{Topical}: query-aware weighted PageRank via anchor/context TF-IDF. \textcolor{cardinal}{\emph{Least forgetting ($-0.02$ MMLU vs.\ $-0.10$ for base).}}
        \item \textbf{Provenance}: editorial quality signal (domain prior, metadata, citation density).
        \item \textbf{Corroborate}: cross-source content agreement with $0.25\times$ same-domain discount. \textcolor{cardinal}{\emph{Lowest anchor NLL drift.}}
    \end{itemize}
